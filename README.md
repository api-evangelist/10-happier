10% Happier (now branded Happier Meditation) is a consumer meditation and mindfulness app founded on the best-selling book "10% Happier" by ABC News anchor Dan Harris. The service delivers personalized, science-backed guided meditations, courses, and sleep content from well-known teachers through native iOS and Android apps and a web player, aimed at helping skeptics and busy people build a sustainable mindfulness practice for stress, sleep, focus, and relationships. It operates on a subscription model. This profile was surfaced as a portfolio company of Trinity Ventures and enriched by the API Evangelist pipeline; 10% Happier is a direct-to-consumer app and does not publish a public developer API, so this record captures its identity, web properties, and domain-security posture.

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for 10% Happier: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
